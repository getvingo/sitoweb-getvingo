Catalogo delle vetture

Marche, modelli e versioni scritti come li volete. Quando si carica o si modifica un'auto, quello che corrisponde al catalogo prende la sua scrittura e le versioni del catalogo sono le prime proposte.

File Excel (.xlsx) o CSV, una riga per versione, con le colonne marca, modello e versione (la versione si può lasciare vuota). Es. Volkswagen ; T-Roc ; 1.5 eTSI 150 CV Life. Righe ripetute e maiuscole diverse contano una volta sola. Il nuovo file sostituisce tutto il catalogo.
